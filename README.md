## ⚙️ Compilation & Execution Guide

### C++ Practicals
Compile any C++ program using modern C++ standards:
```bash
g++ -std=c++20 01_CPP_Practice/05_OOP_Concepts/polymorphism_virtual_functions.cpp -o run
./run
```

### DSA Solutions
Run any verified algorithmic problem:
```bash
g++ -std=c++20 02_DSA_Questions/01_Arrays_and_Hashing/two_sum.cpp -o two_sum
./two_sum
```
